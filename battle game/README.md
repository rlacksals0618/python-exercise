# 권 · 족 · 참 (拳 · 足 · 斬)

팔 공격과 발 공격, 방향키 콤보로 겨루는 2D 격투 게임입니다. 한 키보드로 두 사람이 대전(PVP)하거나 컴퓨터와 대전(PVE)할 수 있습니다.
Python과 [pygame-ce](https://pyga.me/)로 만들었고, 웹 버전은 [pygbag](https://github.com/pygame-web/pygbag)으로 브라우저에서 돌아가게 바꿨습니다.

## 🎮 바로 플레이하기 (웹)

**https://rlacksals0618-collab.github.io/python-exercise/battle-game/**

Chrome이나 Edge로 위 주소를 열면 설치 없이 바로 플레이할 수 있습니다.

- 처음 열 때는 브라우저용 파이썬을 내려받느라 몇 초에서 수십 초 걸립니다.
- 화면을 한 번 클릭해야 키보드 입력이 게임으로 들어갑니다.
- 키 설정과 커맨드 표시 설정은 브라우저에 저장되어 새로고침해도 유지됩니다.
- F1·F11은 브라우저가 먼저 가져갈 수 있습니다(도움말, 전체 화면). 웹에서는 F11 전체 화면 전환을 쓰지 않습니다.

## 🐍 파이썬(.py)으로 실행하기

1. **Python 3.10 이상**을 설치합니다. ([python.org](https://www.python.org/downloads/), 설치할 때 "Add python.exe to PATH" 체크)
2. 터미널(명령 프롬프트, PowerShell)에서 pygame-ce를 설치합니다.

   ```bash
   pip install pygame-ce
   ```

   > 예전 `pygame`이 이미 깔려 있으면 서로 충돌합니다. 먼저 `pip uninstall pygame`으로 지운 뒤 설치하세요.

3. 이 폴더로 이동해서 `batgame.py`를 실행합니다. 폴더 이름에 띄어쓰기가 있으니 따옴표로 감쌉니다.

   ```bash
   cd "battle game"
   python batgame.py
   ```

   VS Code에서는 `batgame.py`를 열고 오른쪽 위 ▶ 버튼을 눌러도 됩니다.

창 크기를 바꾸거나 F11로 전체 화면으로 바꿔도 화면 배치가 유지됩니다.

### 웹 버전 직접 만들기 (선택)

```bash
pip install pygbag fonttools
python build_web.py
python -m pygbag --ume_block 0 web        # 또는 web 폴더를 아무 웹 서버로 열기
```

`build_web.py`가 `web/` 폴더에 웹 파일을 만듭니다. 이 폴더 내용을 GitHub Pages(`gh-pages` 브랜치의 `battle-game/`)에 올리면 위 링크가 새 버전으로 바뀝니다.

## 조작

| 동작 | P1 (기본값) | P2 (기본값) |
|---|---|---|
| 이동 | W A S D | 방향키 |
| 팔 공격 (P) | F | K |
| 발 공격 (K) | G | L |

| 키 | 동작 |
|---|---|
| ↑ / 위 | 점프 (←·→와 함께 누르면 그쪽으로 점프) |
| ↓ / 아래 | 앉기 |
| 상대 반대쪽 방향 | 막기 (서서 막기 / ↓와 함께 앉아 막기) |
| Esc | 일시정지 (기술표·설정·캐릭터 선택으로 이동 가능) |
| F1 | 판정 상자 보기 (파랑 = 맞는 범위, 빨강 = 때리는 범위) |
| F2 | 입력 기록 보기 (콤보 연습용) |

키는 **설정 → 키 설정**에서 바꿀 수 있습니다. 이미 쓰이던 키를 고르면 두 동작의 키가 서로 바뀝니다.

> 한 키보드로 둘이 할 때 키보드에 따라 여러 키를 동시에 누르면 일부 입력이 씹힐 수 있습니다. 이럴 때는 서로 멀리 떨어진 키로 바꿔 보세요.

**커맨드 표시**: 전투 중 화면 왼쪽 위에 콤보·필살기 입력법이 나옵니다(PVP에서는 P2 것이 오른쪽 위에). 키 이름은 현재 키 설정을 따르고, 캐릭터가 왼쪽을 보면 화살표 좌우도 바뀝니다. 지금 쓰는 기술은 금색으로 빛나고, 필살 게이지가 모자라면 게이지 기술은 흐리게 보입니다. **설정 → 커맨드 표시**에서 켜고 끌 수 있습니다.

## 게임 흐름

타이틀 → 모드 선택(PVP / PVE + 난이도) → 캐릭터 선택 → 스테이지 선택 → VS → 전투(3판 2선승) → 결과(재대결 / 캐릭터 선택 / 타이틀)

## 캐릭터

| 이름 | 유형 | 의상 | 체력 | 속도 | 공격력 |
|---|---|---|---|---|---|
| 무진 | 검술 · 남 | 중국풍 무협 도포, 상투와 금관, 술 달린 직검 | 1050 | 보통 | 높음 |
| 설아 | 검술 · 여 | 일본풍 고소데와 하카마, 말총머리, 카타나 | 950 | 빠름 | 보통 |
| 강혁 | 격투술 · 남 | 일본풍 도복과 검은 띠, 붉은 머리띠 | 1080 | 조금 느림 | 가장 높음 |
| 하린 | 격투술 · 여 | 중국풍 무술복(차이나 칼라), 양쪽 쪽머리 | 940 | 가장 빠름 | 조금 낮음 |

캐릭터는 그림 파일 없이 관절 각도로 그리고, 기술마다 정해 둔 자세(키프레임) 사이를 부드럽게 이어서 움직입니다. 머리카락·리본·머리띠·허리띠 끝·칼술은 몸을 따라 흔들리고, 도포·하카마 자락은 다리를 조금 늦게 따라와 출렁입니다. 같은 캐릭터끼리 대전하면 P2는 다른 색 옷을 입습니다.

## 기술

방향은 캐릭터가 **보는 쪽 기준**입니다(`→` = 상대 쪽). 선딜·후딜 단위는 프레임(1/60초)이고, 강한 기술일수록 선딜(나가기 전 준비)과 후딜(끝난 뒤 빈틈)이 깁니다. 데미지·선딜·지속·후딜·판정은 게임 안 **기술표**에서 모두 볼 수 있습니다.

| 입력 | 격투술 (강혁·하린) | 검술 (무진·설아) |
|---|---|---|
| P → P → P | 삼연권: 잽 → 훅 → 올려치기 | 삼단베기: 가로베기 → 역베기 → 내려베기 |
| K → K → K / K → K → P | 삼연각: 앞차기 → 중단 돌려차기 → 뒤후려차기 | 각검연격: 앞차기 → 옆차기 → 내려베기 |
| ↓↘→ + P | 붕권 (파고드는 일격) | 질풍참 (돌진 베기) |
| →↓↘ + P | 승룡권 (무적 대공기) | 승천참 (무적 대공 베기) |
| ↓↙← + P | 장타 (크게 밀어내기) | 회전참 (2연속 베기) |
| ↓↘→ + K | 선풍각 (회전 3연타) | 비연각 (날아차기, 서서 막기) |
| ↓↙← + K | 낙뢰각 (내려찍기, 서서 막기) | 반월각 (반달 발차기) |
| ↓↘→↓↘→ + P | 천붕권 (필살 게이지 MAX) | 일섬 (필살 게이지 MAX) |

- 콤보는 앞 공격이 **맞거나 막혔을 때** 이어서 버튼을 누르면 나갑니다.
- 기본기·연결기가 맞은 직후 필살기 명령을 넣으면 끊고 이어집니다. 예: 잽 → 붕권
- 필살 게이지는 때리거나 맞을 때 차오르고, 라운드가 바뀌어도 유지됩니다.

| 판정 | 막는 법 |
|---|---|
| 상단 | 서서 막기. 앉으면 피할 수 있음 |
| 중단 | 서서 막기 · 앉아 막기 모두 가능 |
| 하단 | 앉아서 막기 |
| 중단 · 서서 막기 (점프 공격, 낙뢰각, 비연각) | 서서 막기 |

필살기를 막으면 체력이 조금 깎입니다(칩 데미지). 막기만 해서는 쓰러지지 않습니다.

## 스테이지 · 이펙트 · 규칙

- **스테이지**: 황야 · 초원 · 뒷골목 · 격투기 링 · 흰 방 · 무작위. 여러 겹의 배경이 서로 다른 속도로 움직여 깊이감이 납니다.
- **카메라**: 게임 세계를 2배로 확대해 보여주고, 두 캐릭터의 가운데를 따라가며 높이 뛰면 함께 올라갑니다. 두 캐릭터가 화면 밖으로 벌어지지 않게 최대 거리가 정해져 있습니다.
- **이펙트**: 맞은 부위에 따라 붓글씨 한자 이펙트가 나옵니다. 拳(빨강) = 팔 공격, 足(초록) = 발 공격, 斬(보라) = 검 공격. 강한 기술일수록 크게 나옵니다.
- **규칙**: 3판 2선승, 한 라운드 99초. 시간이 다 되면 체력이 많이 남은 쪽이 이깁니다. PVE 난이도는 쉬움 · 보통 · 어려움입니다.

## 📁 파일 설명

### 실행 · 설정

| 파일 | 내용 | 용도 |
|---|---|---|
| `batgame.py` | `App` 클래스: 1280×720 창을 만들고 설정·이펙트 이미지를 불러온 뒤, 화면(씬) 관리자를 돌리는 메인 루프. 로직은 초당 60번 고정으로, 그리기는 그 사이를 보간해서 부드럽게 한다. 브라우저에서도 돌도록 `async`로 작성 | **게임 실행 파일.** `python batgame.py`로 시작 |
| `settings.py` | 화면 크기, 무대 범위, 카메라 확대율(2배), 걷기·점프·중력 같은 이동 수치, 라운드 시간·필살 게이지 같은 전투 규칙, 기술 강도별 히트스톱·흔들림·이펙트 크기, 색 | 게임 전체에서 쓰는 **숫자를 한 곳에 모아 둔 파일.** 밸런스 조정은 여기서 |
| `controls.py` | 키 설정(`KeyConfig`): P1/P2 키 배치와 옵션 저장·불러오기, 키가 겹치면 서로 바꾸기. 키보드 입력을 `up`·`punch` 같은 동작으로 바꾸는 `KeyboardController`. 최근 입력을 기억해서 ↓↘→ 같은 명령을 찾는 `InputBuffer` | **입력 처리.** 데스크톱에서는 `config.json`, 웹에서는 브라우저 저장소에 설정을 저장 |
| `build_web.py` | 게임에 필요한 파일만 임시 폴더에 모으고, 글꼴을 쓰는 글자만 남게 줄인 뒤(17MB → 0.6MB), pygbag으로 빌드해서 `web/` 폴더에 웹 파일을 만든다 | **웹 버전 만들기.** 게임을 고친 뒤 웹 링크를 새로 올릴 때 실행 |
| `.gitignore` | `__pycache__/`, `web/`, `config.json`을 저장소에서 제외 | 자동으로 생기는 파일을 GitHub에 올리지 않게 함 |
| `README.md` | 이 문서 | 게임 소개, 실행 방법, 파일 설명 |

### 저장소에 올리지 않는 파일 (자동 생성)

| 파일 | 생기는 때 | 내용 |
|---|---|---|
| `config.json` | 게임에서 키 설정이나 커맨드 표시를 바꾸면 | 각자의 키 배치와 옵션 |
| `web/` | `python build_web.py`를 실행하면 | 웹 버전 파일(`index.html`, `battle_game.apk` 등). `gh-pages` 브랜치에 따로 올려 배포 |
| `__pycache__/` | 파이썬을 실행하면 | 파이썬이 만드는 실행 캐시 |
